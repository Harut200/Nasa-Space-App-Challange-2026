## 7. How to reproduce

From [DETECTION.md](DETECTION.md) section 9 and the write-ups. Run one heavy job at a time (Tonle Sap needs 2-3.5 GB per process). Times are from the module notes on an Apple-silicon laptop. Every script path below was checked to exist. Server steps need `SERVER` and `SSH_KEY` in the environment; no address is stored in the repository.

```bash
# environment
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt -r requirements-detect.txt

# tests (this record)
.venv/bin/python -m pytest tests -q -rA 2>&1 | tee docs/evidence/pytest-full.txt     # about 2 minutes
cd src/app && npm test 2>&1 | tee ../../docs/evidence/app-tests.txt                   # no build, no dev server

# data
.venv/bin/python scripts/ingest/fetch_previews.py tonle-sap       # also: sevan
.venv/bin/python scripts/ingest/add_area.py <id> --name "Name, Country" --bbox W S E N

# detection methods and validation (D01-D14, V01-V03)
.venv/bin/python -m scripts.detect.eda                      # about 65 s
.venv/bin/python -m scripts.detect.detect_math tonle-sap    # also sevan, ararat
.venv/bin/python -m scripts.detect.qc                       # every area
.venv/bin/python -m scripts.detect.terrain
.venv/bin/python -m scripts.detect.floodveg --report tonle-sap     # about 5 min
.venv/bin/python -m scripts.detect.stats_change             # about 80 s
.venv/bin/python -m scripts.detect.gmm
.venv/bin/python -m scripts.detect.graphdet                 # about 20 min
.venv/bin/python -m scripts.detect.subpixel
.venv/bin/python -m scripts.detect.tune                     # about 3.5 min
.venv/bin/python -m scripts.detect.fusion && .venv/bin/python -m scripts.detect.scoreboard
.venv/bin/python -m scripts.detect.hydro tonle-sap          # about 25 s
.venv/bin/python -m scripts.detect.crossscene               # about 25 min (--skip-grid about 6 min)
.venv/bin/python -m scripts.detect.fusion2 --final
.venv/bin/python -m scripts.detect.novel tonle-sap          # also sevan as null control
.venv/bin/python -m scripts.detect.validate                 # Landsat water record (V01)
.venv/bin/python -m scripts.detect.validate_2026            # weather, gauges, altimetry (V02)
.venv/bin/python -m scripts.detect.opera catalogue          # then queue, compare, report (V04)

# calibrated data and interferometry (C01-C02, I01-I02)
scripts/ingest/remote_run.sh tonle-sap                      # server job; laptop writes GeoTIFFs
.venv/bin/python -m scripts.detect.calibrated tonle-sap-cal --step water --evals 40
.venv/bin/python -m scripts.detect.insar coherence          # also: fetch, motion, sm, tonle, layer

# earthquakes and other ground events (Q01-Q06, G01-G04)
.venv/bin/python -m scripts.detect.quake list               # then launch, fetch, run, export, overview
.venv/bin/python -m scripts.detect.events list              # then resolve, launch, fetch, run, export, overview

# learned models (L01-L07)
.venv/bin/python -m scripts.detect.train unet --version v2_t_d3
.venv/bin/python -m scripts.detect.deep_ae sweep --jobs 1
.venv/bin/python -m scripts.detect.ttransformer train --area tonle-sap --variant ctx5res --epochs 8
.venv/bin/python -m scripts.detect.foundation download ai4g     # also: alos2
.venv/bin/python -m scripts.detect.despeckle evaluate --areas tonle-sap --no-final
.venv/bin/python -m scripts.detect.unmix evaluate
.venv/bin/python -m scripts.detect.supervised train --holdout sevan,tonle-sap --products

# app data and the app
.venv/bin/python scripts/detect/run.py tonle-sap && .venv/bin/python scripts/ingest/export.py tonle-sap
.venv/bin/python scripts/ingest/optimize.py                 # data-size optimiser; see docs/eda/data-size.md
cd src/app && npm install && npm run dev
```
